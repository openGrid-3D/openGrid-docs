## Ecosystem partners

### Underware
**by HandsOn Katie** — cable management system compatible with openGrid Lite boards.
- [Official Underware 2.0 collection](https://handsonkatie.com/underware-2-0-the-made-to-measure-collection/)
- See also: [Underware integration guide](./projects/underware/)

### Multiconnect
**by DavidD (openGrid creator)** — universal adapter system that works across multiple board types, giving access to a large library of existing accessories.

### Gridfinity
The mathematical grid relationship (2 Gridfinity units = 3 openGrid units = 84mm) means many Gridfinity accessories work directly with openGrid. See the [Gridfinity integration guide](./projects/gridfinity/) for details.

## Contributing designs

When sharing openGrid-compatible designs:

- Use the `openGrid` tag on Printables and MakerWorld for discoverability
- Include clear photos and print settings
- Note whether the design targets the lite board, full board, or both
- Provide source files (STEP or OpenSCAD) so others can remix

**Design guidelines:**
- 28mm grid compatibility
- Front-side access (no wall access needed after mounting)
- Keep aesthetics clean — openGrid is designed for living rooms, not just workshops

**CC-BY 4.0 requirements:** Attribution is required for derivative works. Commercial use is allowed; share-alike is not required.
